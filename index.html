// O problema

Hoje, usar cripto significa
abrir mão da privacidade.

A blockchain é pública por design. Isso é bom para auditabilidade — mas péssimo para a privacidade financeira de quem usa no dia a dia.

  • Transações são públicas e rastreáveis por qualquer pessoa

  • Seu histórico financeiro completo fica exposto permanentemente

// O fluxo em detalhe

Do envio ao recebimento

Veja como sua transação percorre o protocolo — com privacidade em cada etapa.

📤

Endereço temporário gerado

Um endereço descartável é criado exclusivamente para essa transação. Você envia os fundos para ele — nunca direto para o destino final.

Criado on-demand · expira em 60 min
✂️

Divisão em partes

O valor é dividido em múltiplas partes com denominações padronizadas. Isso elimina a correlação direta entre o valor de entrada e saída.

Split com denominações fixas
🔀

Roteamento com delays variáveis

Cada parte percorre múltiplos endereços intermediários com delays aleatórios entre etapas. Análise temporal e rastreamento on-chain ficam extremamente difíceis.

3 hops por split · delays 60–360s
🎯

Depósito em stealth address

Os fundos são depositados em um endereço stealth — invisível para observadores externos. Só quem tem as chaves corretas consegue encontrá-lo.

Stealth address · invisível on-chain
💸

Saque gasless para qualquer carteira

O protocolo cobre o gas do saque. Você pode sacar para sua carteira principal, para uma carteira fria, para o endereço de depósito de uma exchange — ou para qualquer outro endereço.

Gas pago pelo protocolo · ~20 minutos no total
